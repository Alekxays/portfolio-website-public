# Design system - Alexandre Boissel portfolio

## Hallmark
- Genre: modern-minimal
- Theme: cobalt (adapted for personal portfolio)
- Macrostructure: Portfolio Grid
- Nav: hairline bordered bar + locale switch
- Footer: compact credit strip

## Tokens
- Paper: cool near-white oklch(~98.5% 0.004 250)
- Ink: cool charcoal oklch(~24% 0.02 258)
- Accent: electric cobalt oklch(58% 0.20 256)
- Radii: 6px controls, 10px media
- Hairlines for structure; no decorative cards

## Type
- Display / body: Space Grotesk
- Labels / meta: JetBrains Mono (uppercase, tracked)

## Motion
- Section reveal: fade + 10px rise
- Nav underline grow on hover
- Modal open/close
- Respects prefers-reduced-motion

## Deviations from Cobalt canonical
- No ⌘K palette (personal site, not a product)
- No code-demo hero - brand name + portrait as hero signal
- Body font: Space Grotesk (not Inter)
