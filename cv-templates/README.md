# CV templates (portfolio DA)

HTML/CSS print templates aligned with the site: **Space Grotesk + JetBrains Mono**, monochrome paper/ink, hairline rules, mono eyebrows.

## Files

| File | Use |
| --- | --- |
| `cv-fr.html` | French CV |
| `cv-en.html` | English CV |
| `cv.css` | Shared styles (A4) |

## Edit → PDF

1. Open `cv-fr.html` or `cv-en.html` in a browser.
2. Edit the HTML (sections, bullets, stack).
3. **Cmd/Ctrl + P** → destination **Save as PDF** → paper **A4** → margins **None**.
4. Upload the PDF in **Studio → Profile** (or replace `public/files/…`).

The sheet is locked to **one A4 page** (`210×297mm`, `overflow: hidden`).  
Tip: disable browser headers/footers in the print dialog.
